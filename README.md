# DesktopPet 🐾 다운로드

맥 바탕화면을 돌아다니는 픽셀 펫 + 메모·할 일 위젯이에요.

고양이·강아지·키위·까마귀·말랑이·코주부원숭이·도마뱀·햄스터가 창 위를 걷고, 먹고, 자고, 서로 인사해요.

## 👉 [DesktopPet.zip 받기](https://github.com/salad-desktop-pet/desktop-pet-download/releases/latest/download/DesktopPet.zip)

macOS 15 이상 · 인텔 / 애플 실리콘 맥 모두 · 윈도우는 안 돼요

## 설치 (처음 한 번)

1. 받은 zip 을 더블클릭해서 풀고, `DesktopPet` 을 **응용 프로그램** 폴더로 옮겨요
2. 더블클릭해서 열면 *"확인할 수 없습니다"* 창이 떠요 → **완료**
3. **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 *"DesktopPet 이(가) 차단되었습니다"* 옆 **그래도 열기** → 암호 입력
4. 메뉴바에 🐾 가 생기면 끝! 다음부터는 그냥 열려요

> 애플 유료 개발자 인증을 받지 않은 앱이라 처음 한 번 허용이 필요해요.
> 메모는 내 맥에만 저장되고, Claude·구글·리니어 같은 연동은 직접 연결했을 때만 써요.

## 쓰는 법

- 🐾 → **펫 추가** 에서 펫 고르기 (펫을 우클릭하면 먹이·재우기·캐릭터 바꾸기)
- 바탕화면의 **메모** 막대를 누르면 메모·할 일 보드가 펼쳐져요. 우클릭으로 스킨 바꾸기
- `⌘⇧M` 어디서든 빠른 메모

## 연동 (선택 — 안 해도 펫·메모는 다 돼요)

| 하고 싶은 것 | 필요한 연동 | 난이도 |
| --- | --- | --- |
| 회의 시작 전 펫이 알려주기 | 맥 캘린더 권한 | ⭐ |
| 맥 알림을 펫이 말풍선으로 읽어주기 | 손쉬운 사용 권한 | ⭐ |
| 펫과 대화, 빠른 메모 자동 정리, 아침 브리핑 | Claude Code | ⭐⭐ |
| 메모 위젯 **이슈** 탭 (내 리니어 이슈 칸반) | 리니어 API 키 | ⭐ |
| 하루·주간 마무리를 Obsidian 노트로 | Claude Code + Obsidian | ⭐⭐ |
| 펫한테 구글챗·동료 일정 물어보기 | Claude Code + 구글 계정 | ⭐⭐⭐ |

### 📅 캘린더 (일정 알림)
1. 🐾 → **알림·연동** → **캘린더 권한 설정…** → 허용
2. 맥 **캘린더 앱**에 들어 있는 일정을 봐요. 구글 캘린더를 쓰면 *시스템 설정 → 인터넷 계정* 에 구글 계정을 추가해 두면 돼요
3. 매시 25분·55분에 곧 시작하는 회의를 알려줘요

### 🔔 알림 읽어주기
1. 🐾 → **알림·연동** → **알림 권한 설정…**
2. *시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용* 에서 **DesktopPet** 켜기 → 앱 다시 열기

### 🤖 Claude Code (대화·정리의 두뇌)
Claude 유료 요금제(Pro/Max) 계정이 필요해요.
1. **터미널** 앱을 열고 아래 한 줄을 붙여넣고 엔터
   ```sh
   curl -fsSL https://claude.ai/install.sh | bash
   ```
2. 터미널에 `claude` 입력 → 안내대로 브라우저에서 로그인
3. DesktopPet 을 다시 열면 펫 우클릭 → **대화하기 💬** (어디서든 `⌘⇧K`) 로 대화할 수 있어요

### 📋 리니어 (이슈 탭)
Claude Code 없이 돼요.
1. 리니어 → **Settings → Security & access → Personal API keys** 에서 키 만들기 (읽기 권한이면 충분)
2. 메모 위젯 → **이슈** 탭 → 오른쪽 위 🔑 → 키 붙여넣고 **저장하고 가져오기**
3. 이후엔 ↻ 를 누를 때마다 1~2초 만에 새로 가져와요. 키는 이 맥의 앱 폴더에만, 나만 읽을 수 있는 파일로 저장돼요

### 🌙 Obsidian (하루·주간 마무리)
Claude Code 를 먼저 설치하세요.
1. [Obsidian](https://obsidian.md) 에서 볼트를 하나 열어 두면, 가장 최근에 연 볼트를 자동으로 써요
2. 🐾 → **하루 마무리 받기 🌙** / **주간 마무리 받기 📆** → 볼트의 `daily_summary/`, `week_summary/` 폴더에 노트가 생겨요

### 💬 구글챗·구글 캘린더 (고급)
구글은 앱마다 *OAuth 클라이언트* 를 직접 만들어야 해서 단계가 많아요. 회사 구글 계정이면 관리자가 막아 뒀을 수도 있어요.
1. [Google Cloud 콘솔](https://console.cloud.google.com) 에서 프로젝트 만들기
2. **API 및 서비스 → 라이브러리** 에서 **Google Chat API**, **Google Calendar API** 사용 설정
   (Chat API 는 *구성* 탭에서 앱 이름·아이콘 등을 채워 저장해야 할 수 있어요)
3. **OAuth 동의 화면** 설정 → **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 데스크톱 앱** → JSON 다운로드
4. 🐾 → **알림·연동** → **구글챗 연결…** → 받은 JSON 고르기 → 브라우저에서 로그인
5. 펫한테 "구글챗 뭐 왔어?", "○○님 내일 일정 비어 있어?" 하고 물어보면 돼요 (읽기만 해요)
